# Product Context: Ahmad Elshowair Portfolio

## Register
brand

## Product Purpose
Personal engineering portfolio and interactive resume showcase for Ahmad Elshowair, a Senior-caliber Full-Stack Developer specializing in React 19, Next.js 16, TypeScript, Node.js, PostgreSQL, Redis, and high-performance web systems.

## Target Audience
- Technical recruiters seeking proven full-stack and frontend capabilities in under 15 seconds.
- Engineering hiring managers, Tech Leads, VPs of Engineering, and CTOs evaluating system design depth, technical craft, attention to detail, and production rigor.

## Core Value Proposition
- Demonstrable, verified production evidence behind every claimed skill (PointCraft POS, ClearCarGo, Post-It, Kun Min Aldhaakirin).
- High-craft, memorable user experiences demonstrating frontend mastery, accessibility (WCAG AA), and performance without relying on generic templates.

## Anti-References & Banned Patterns
- **No gradient text** (`background-clip: text` with gradient).
- **No side-stripe colored borders** (`border-l-4` accent lines).
- **No cookie-cutter SaaS cards** (monotonous grids of identical icon + title + paragraph).
- **No unverified metrics** (Article VIII: every claim must match canonical resume verbatim).
- **No theme or palette deviation**: Never introduce arbitrary neon, purple, blue, or unapproved accent colors. The palette is strictly locked.
- **Never strip glassmorphism**: Glass surfaces (`backdrop-blur-md`, translucent fills, subtle green glows) are a core ratified design signature.
